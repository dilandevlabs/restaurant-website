# Restaurant Landing Page

A modern and responsive restaurant website designed to showcase the restaurant's identity, menu, services, and overall dining experience.

## Overview

This project focuses on creating a clean and welcoming digital presence for a modern restaurant. The design combines warm neutral tones with deep green and gold accents to create an elegant but approachable visual identity.

## Features

- Responsive layout
- Modern restaurant-focused design
- Hero section with call-to-action
- Menu showcase
- Restaurant information
- Image gallery
- Testimonials
- FAQ section
- Contact section
- Responsive navigation and footer

## Technologies

- HTML5
- CSS3
- JavaScript

## Design

The visual identity uses a warm, natural color palette:

- Deep Green — `#1F3D34`
- Gold — `#B9975B`
- Warm Background — `#F5F1E8`

Typography combines Montserrat for a clean modern appearance with Playfair Display for decorative headings.

## Purpose

This project was created as a frontend practice project to improve responsive design, visual hierarchy, UI composition, and the implementation of real-world business websites.
